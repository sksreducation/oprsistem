# 📋 Generator OPR Mobile - SK Simpang Rawai

Sistem aplikasi web mesra telefon bimbit untuk membina **One Page Report (OPR)** rasmi Sekolah Kebangsaan Simpang Rawai. Sistem ini menyokong penjanaan AI untuk Objektif & Impak serta menyimpan rekod borang terus ke **Google Sheets**.

---

## 🌟 Ciri-ciri Utama
- 📱 **Mesra Mobil (Mobile-First):** Boleh diakses dan diisi terus melalui telefon bimbit.
- ✨ **AI Generator:** Menjana Objektif & Impak cadangan secara automatik mengikut tajuk program.
- 🖼️ **Muat Naik Gambar:** Menyokong pautan gambar aktiviti dan logo sekolah.
- 📊 **Integrasi Google Sheets:** Menghantar rekod borang terus ke Google Sheets menerusi Google Apps Script backend.
- 🖨️ **Cetak / PDF:** Boleh dicetak terus atau disimpan dalam format PDF saiz A4.
