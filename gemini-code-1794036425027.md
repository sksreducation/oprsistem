# 📋 Generator OPR Mobile - SK Simpang Rawai

Sistem Pembangkit **One Page Report (OPR)** rasmi untuk Sekolah Kebangsaan Simpang Rawai yang mesra telefon bimbit.

## 🌟 Ciri-ciri Utama
- 📱 **Mobile-First Design:** Boleh diisi terus menggunakan telefon bimbit di mana-mana sahaja.
- ✨ **AI Generator:** Penjanaan automatik Objektif dan Impak program berasaskan tajuk.
- 🖼️ **Auto-Compress & Drive Upload:** Gambar diproses dan disimpan secara automatik ke dalam Google Drive peribadi.
- 📊 **Google Sheets Integration:** Data disimpan secara terus ke dalam Google Sheet backend.
- 🖨️ **Eksport PDF / Cetak:** Menyediakan format A4 sedia cetak.
